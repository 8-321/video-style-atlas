## 怎么用（3 步）

1. **先选风格**：双击 `index.html` 看预览墙，或按上表的「适合」和「规格」选一个 ID。不要混用两套视觉系统。
2. **打开卡片**：`卡片\Sxx-*.md`。里面有成片证据、色值、字体、镜头、声音、结构、提示词锚点、验收数字和坑。
3. **复制参数**：提示词锚点直接粘到生成工具；字幕/音频/画幅参数直接抄；出片后按卡片最后一节「验收数字」逐条核对。

想要「同一套视觉、换一种讲法」，到 `叙事骨架.md` 里换 N01–N10 中的一套，不要重做视觉。

## 要复刻一条现成的片子 → 先看工作流

风格卡管「长什么样」，`复刻工作流.md` 管「工序怎么排」。8 条流程：

| 编号 | 流程 | 适合 |
|---|---|---|
| W00 | 通用拆片法（6 层数字） | 任何「我想做成这样」的参考片 |
| W01 | Lovart 脚本优先 · 逐帧关键帧（官方 5 步） | 没拍摄条件、要控画面 |
| W02 | Lovart 五段式镜头提示词公式 | 所有生成式镜头 |
| W03 | 扣子漫画/漫剧四段工作流 | 一个主题 → 一条成片 |
| W04 | 抖音影视解说七技能（先剪后配） | 影视/短剧解说号 |
| W05 | 短剧/漫剧 11 技能（原著→成片） | 有剧本、要连续追更 |
| W06 | 长视频实拍解说（本机实测基线） | 复刻某个具体的人 |
| W07 | 一稿多平台（9:16 / 16:9 / 1:1 / 缩略图） | 一条内容多平台发 |

**铁律**：先判断你复刻的是 look / beats / pipeline 哪一层。三层混着抄，一定翻车。

## 三条铁律

- **一套片子只用一个视觉系统**。S05 的黑金不要混 S01 的撕纸；S02 的暖木桌不要混 S09 的近黑底。
- **先定画幅和交付形态，再写稿**。纯画面交付（S05/S06）和带字幕交付（S04）在写稿阶段就要分开。
- **验收看数字，不看感觉**。每张卡最后都有「验收数字」，至少核对：时长、分辨率、帧率、镜头数、字幕位置、响度、黑帧。

## 新增一套风格

1. 复制 `模板\风格卡模板.md` → `卡片\Sxx-名字.md`，填满。
2. 在 `styles.json` 的 `styles` 数组里加一条。
3. 在 `工具\build_previews.py` 的 `STYLES` 里加一条（给成片路径、图片路径，或用 `kind="specimen"` 画规范示意板），运行：

```powershell
& "C:\Users\34137\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" -X utf8 "E:\视频工厂\10-风格库\工具\build_previews.py"
```

4. 运行 `工具\build_index.py` 重建风格墙；在 README 的选型表加一行。

> 注意：本机 PATH 里的 `python` 是空壳，必须用上面这个 Codex 运行时 Python（它带 Pillow）。
