## 镜头与动效

- 场景停留：**4–6 秒**，最短不低于 3.5 秒。
- 场景内用 **2–3 张同构图微变图**（光角、叶子、粒子、姿态微变）**交叉淡化 1–1.5 秒**模拟运动。
- 转场：`crossfade / drift / dissolve`，时长 **1.0 秒**。
- 入场：淡入 + 上浮 8px，1 秒；出场：0.8 秒淡出。
- 缓动：`spring(1, 60, 20)`，**不过冲**。
- 每个场景至少一个动元素（萤火虫/粒子/镜头缓移）；每张图都加暗角。

## 声音与字幕

- 旁白：温暖、慢、讲故事的语气，像哄睡。
- BGM：钢琴/弦乐/环境声，久石让式但不抄旋律；**音量 0.15**。
- 音效：风、水、鸟、轻微魔法铃；禁止刺耳音效。
- 响度：−14 LUFS；ducking −3 dB。
- 字幕：**不要烧进生成图**；用 Remotion/ffmpeg 叠加，避免错字与风格破坏。

## 生产链

- 规范：`OpenMontage\styles\anime-ghibli.yaml`
- 生成：每场 2–3 张微变图（同 prompt + 同 seed 族），交叉淡化
- 组装：ffmpeg `xfade` / Remotion `<TransitionSeries>`
- 可复用：色板、`consistency_anchors`（6 条）、每场图数规则

## 验收数字

- [ ] 单场 4–6 秒，全片无快切
- [ ] 每场 2–3 张图，交叉淡化 1–1.5 秒
- [ ] 前中后景都能指出来
- [ ] 每张图都有暗角、每个场景都有动元素
- [ ] 生成图内无文字
- [ ] 色板跨场一致（同 seed 族）
- [ ] BGM ≤0.15，环境声可闻

## 坑

- **加 3D 就死**：一有体积光/景深渲染感，立刻不是手绘。
- **快切毁气氛**：这套靠「慢」成立，剪辑点少于 3.5 秒就变 PPT。
- **文字让模型画**：中文必错，一律后期叠。
- **角色版权**：可以学「手绘水彩动画」这套语言，不要复刻具体作品角色。
- **只生成 1 张图**：没有微变图就没有「呼吸感」，会像幻灯片。
