## 什么时候用

- 3–4 分钟短片、漫剧、世界观展示、IP 先导片。
- 想要「电影感 + 高完成度 + 无口播」，靠画面和音乐叙事。
- 21:9 超宽银幕，适合 B 站/视频号/线下展映。
- 想让 AI 一次读完整剧本、自己拆单元出片，而不是你逐镜抽卡。
- **不适合**：知识解说、产品功能、需要大量文字信息的题材；也不适合需要精确口型/台词的戏。

## 画面实测指纹

采样法：每镜按 6/20/36/52/68/84/96% 取 7 帧，缩到 160×90，共 403,200 像素。

| 指标 | 实测 | 怎么用 |
|---|---|---|
| 分辨率 | 1280×720（16:9） | 样片是 720p 试机；21:9 是成片目标，不是已验事实 |
| 帧率 | 24fps，H.264 / yuv420p | 直接对齐 24fps，别用 30fps 素材混剪 |
| 音轨 | **无**（4 个 clip 全无音频流） | 声音必须另做；别指望生成器带 |
| 硬切 | **0**（scene>0.25 全片检不出） | 模型给的是长镜，切点要后期剪 |
| 运动能量 | 6fps 平均帧差 15.7–17.4 /255 | 持续运动，没有静止镜头；不要写「静帧」 |
| 平均亮度 | 98.7（p10 14.3 / p90 198） | 高反差：亮部到 198，暗部压到 14 |
| 分段亮度 | 外景首镜 135.0 / 外景动作 105.5、97.2 / 室内酒吧 57.0 | 室内段允许掉一半亮度，这是有意的 |
| 色温 | R>B 像素占 **87.2%**，平均 R−B **+28.6** | 全片暖调；冷色只做点缀 |
| 亮部 | `#C9BCA9`，R−B +31.7 | 高光偏象牙，不偏白 |
| 暗部 | `#1F140E`，R−B +17.5 | **阴影是暖棕，不是文案写的「偏青」** |
| 饱和度 | 0.389 | 中高饱和；不是褪色文艺片 |
| 主色 8 色 | `#B3AA9B` 13.6% / `#DDCFBB` 12.8% / `#110603` 13.3% / `#5C4737` 13.3% / `#3E2B1E` 12.6% / `#A07F63` 11.7% / `#241D17` 11.5% / `#736E65` 11.1% | 象牙+沙+焦糖+胡桃木+近黑，几乎五等分 |
| 冷强调 | `#63BAD2`（角色参考）/ `#6FB9D1`（画面亮青） | 面屏、水面、天空；面积 <3% |
| 暖强调 | `#74363A`（围巾） | 唯一饱和红；别扩散到别处 |

**三条结论**：

1. **冷暖比例是 9:1**，不是「青橙对撞」。整幅画面在暖色带里，冷色只做眼睛/水面的一点信号。
2. **明暗跨度大**（p10→p90 = 14→198），这是「照片级」的来源；压平对比会立刻变游戏过场。
3. **同一套光要分内外**：外景黄金时刻（135/105/97），室内暖木+顶光（57）。不要给室内补成外景亮度。

**资产锁定四步**（对方真正做对的地方）：

1. 先出**四视图**（正/侧/背 + 半身特写），纯灰底、平光、无场景，2048×2048。
2. 把表情**写成颜色表**，不靠形容词：蓝/绿/黄/红/紫粉 各有唯一含义。
3. 每个角色固定一套服装、比例、道具；**只有面屏图标和颜色允许变**。
4. 全片复用同一张参考图（或同一 seed）；设定图**不进正片**。

**优先级**：角色一致性 > 动作可读性 > 场景连续性 > 运镜复杂度 > 装饰细节。

## 镜头与动效

- 单镜 2–4s；平均 3.82s（214 ÷ 56）。
- 运镜只有五种，按用途选：环境=升降/航拍环绕；日常喜剧=跟随+轻快环绕；打斗=低机位跟拍+短促旋转；恋爱=稳定长焦缓推/柔和横移；太空=缓慢拉远。
- 动作镜头允许硬切和匹配剪辑；恋爱蒙太奇用柔和硬切或物件匹配切。
- 每个镜头**只写一个主动作**；失败先减动作，不加形容词。
- 禁止：频繁闪白、旋转眩晕、无目的变焦、慢动作滥用、时间重映射抖动。

## 声音

- 无对白、无旁白、无口型；表情交给面屏。
- 三段式：0:00–1:39 复古冲浪摇滚 132BPM（原创，不抄旋律）→ 1:39–2:10 **全静音只剩风与脚步** → 2:10–3:25 灵魂乐慢板 74BPM → 3:25 渐弱到只剩飞船低频。
- 八个必须踩中的节拍：00:23 踢头、00:43 异响、00:51 反应、01:18 按钮、01:39 静音、02:10 吉他进入、02:38 照片吐出、03:09 入轨。

## 坑

- **单次生成 214s 必漂**：官方单段 30s；拆 10 单元，尾帧留 8–12 帧再接首帧。
- **样片 0 硬切**：别把 12s 长镜当成分镜成果直接发，必须按 2–4s 重剪。
- **样片全无音轨**：声音是独立工序，不是生成的一部分。
- **「阴影偏青」是文案意向，实测没复现**：暗部 R−B = +17.5，是暖棕。要冷影就明写 `冷影`，并接受它和整片暖调打架。
- **21:9 直发会被平台裁边**：必须另出 16:9 安全区导入版（中央 80%）。
- **角色一致性优先于动作**：某镜失败先减少同镜动作数量，不要加更多形容词。
- **不要赛博朋克**：紫蓝霓虹、现代城市、现代服装会直接破年代。
- **R1 不能长出人脸**：面屏像素眼是唯一表情；禁止牙齿/皮肤/头发。
- **R2 不是活人**：不眨眼、不说话、不换装；姿态可被摆成约会姿势。
- **同镜头内丧尸脸不能复制**：人群造型可变，但同一帧不能出现同一张脸。
- **卡片数字要回原文核**：上一版单元表就是照模板填出来的，全错。
