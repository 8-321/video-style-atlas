## 镜头与动效（精确时间轴）

| 时间 | 动作 | 参数 |
|---|---|---|
| 0.00–0.85 | 纯黑蓄势 | 无元素 |
| 0.85–2.25 | 机身负淡入 | 透明度 smoothstep；上浮 30px→0；缩放 0.962→1.000（缓出三次方） |
| 2.15–2.65 | 屏幕微亮 | 遮黑层 1→0.90（10%） |
| 2.65–3.45 | 屏幕全亮 | 遮黑层 0.90→0；亮度 0.80→1.00 |
| 2.45–3.50 | 玻璃光扫 | 光带 x −320→+505px；峰值 0.5 |
| 2.50–4.30 | 环境辉光起搏 | 基础 0.50 + 脉冲 0.62，随后回落 |
| 3.45–4.20 | 落定首页 | 首页推镜 1.010→1.062（4.2–9.4s） |
| 4.20–43.60 | 9 屏巡游 | 每屏 3.8–5.2s；0.9s 交叉溶解；Ken Burns 1.004–1.240；8–14px 垂直漂移，相邻反向 |
| 43.60–44.00 | 定格商品详情 | 推镜收尾 |
| 44.00–44.90 | 整画淡出到纯黑 | smoothstep |

## 坑

- **必须用 750×1624 @2x 定稿原图**，不要聊天压缩图；放大后会糊。
- **逐帧渲染帧号 = N/30 秒**：不要用 ffmpeg 的 `-r` 重采样，会丢帧/抖动。
- **屏幕内容用 `object-fit: cover` + Ken Burns**：不要拉伸。
- **9 屏顺序别乱**：这是产品叙事，不是随机轮播。
- **收尾必须回到纯黑**：否则不能循环，也不像发布会开场。
