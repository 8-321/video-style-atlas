# S10 胶片化 · 可叠加滤镜

> 一句话：一条 FFmpeg 链，把任何 AI/实拍素材变成「退色、暖高光、泛光、颗粒、暗角」的胶片质感。

**别名**：vintage film look / 胶片化 / 自传微电影调色 / 2.39:1 遮幅  
**状态**：已验证（前后对照）  
**预览**：`E:\视频工厂\10-风格库\预览\S10.jpg`

---

## 什么时候用

- AI 生成的视频「太数码、太干净」，需要压成胶片感。
- 自传微电影、回忆、年代戏、人物短片。
- 想快速统一不同素材的影调，不想逐镜调色。
- 不适合：需要高饱和、明亮、现代感的产品片。

## 视觉系统（配方）

| 步骤 | 作用 | 参数 |
|---|---|---|
| 1 退色曲线 | 抬黑 0.045、高光软压缩 0.955 | `curves=all='0/0.045 0.25/0.235 0.5/0.50 0.75/0.78 1/0.955'` |
| 2 色平衡 | 阴影偏冷、高光偏暖 | `colorbalance=rs=-0.022:bs=0.035:rm=0.012:bm=-0.012:rh=0.048:gh=0.012:bh=-0.05` |
| 3 对比/饱和 | 轻降饱和 0.87，避免数码艳 | `eq=contrast=1.06:saturation=0.87:brightness=-0.004` |
| 4 泛光（类 halation） | 高光溢出，暖光晕 | `curves=all='0/0 0.74/0 1/1',colorchannelmixer=rr=1.28:gg=0.72:bb=0.66,gblur=sigma=10` + `blend=all_mode=screen:all_opacity=0.28` |
| 5 暗角 | 压四角 | `vignette=PI/4` |
| 6 颗粒 | 胶片颗粒 | `noise=alls=7:allf=t+u` |
| 7 可选遮幅 | 2.39:1 | `scale=1280:535:flags=lanczos,pad=1280:720:0:92:black` |

## 完整命令

```bash
bash "E:/AI视频工程/自传微电影/scripts/film_look.sh" 输入.mp4 输出.mp4 scope 7
# 或
bash "E:/AI视频工程/自传微电影/scripts/film_look.sh" 输入.mp4 输出.mp4 plain 7
```

脚本内部：

```bash
FILTER="[0:v]split[base][hl];\
[hl]curves=all='0/0 0.74/0 1/1',colorchannelmixer=rr=1.28:gg=0.72:bb=0.66,gblur=sigma=10[glow];\
[base][glow]blend=all_mode=screen:all_opacity=0.28[halo];\
[halo]curves=all='0/0.045 0.25/0.235 0.5/0.50 0.75/0.78 1/0.955',\
colorbalance=rs=-0.022:bs=0.035:rm=0.012:bm=-0.012:rh=0.048:gh=0.012:bh=-0.05,\
eq=contrast=1.06:saturation=0.87:brightness=-0.004,vignette=PI/4,noise=alls=7:allf=t+u[look];"
```

编码：`libx264 -crf 18 -preset medium -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart`。

## 参数怎么调

| 想要 | 改什么 |
|---|---|
| 更旧/更灰 | `curves` 抬黑从 0.045 加到 0.06；饱和从 0.87 降到 0.80 |
| 更暖 | `colorbalance` 的 `rh` 从 0.048 加到 0.07，`bh` 更负 |
| 光晕更强 | `blend` 的 `all_opacity` 从 0.28 加到 0.36 |
| 颗粒更粗 | `noise=alls` 从 7 加到 10–12 |
| 不要遮幅 | 第三个参数用 `plain` |
| 更电影的比例 | 第三个参数用 `scope`（2.39:1） |

## 验收数字

- [ ] 黑位抬起但不发灰：暗部有细节，纯黑仍在
- [ ] 高光不爆：人脸/天空有层次
- [ ] 肤色不脏：暖而不橙
- [ ] 颗粒均匀，无块状噪点
- [ ] 遮幅模式下上下黑边对称（720p：上 92 / 下 93）
- [ ] 抽 3 帧与原始帧并排对照，能看出「同一个调」

## 坑

- **`colorchannelmixer` 用命名参数**（`rr=`/`gg=`/`bb=`）是安全的；如果改成位置参数，必须写满 16 个值，否则蓝通道会爆（SpaceX 项目踩过）。
- **不要用 `brightness` 抬黑**：会抬死灰；用 `curves` 抬黑。
- **泛光层要先 `curves` 压掉暗部**，否则整幅画面发雾。
- **颗粒加在最后**：在颗粒后再缩放会糊掉颗粒。
- **遮幅会改变构图**：拍/生成时主体别贴边，否则 2.39:1 会切头。
