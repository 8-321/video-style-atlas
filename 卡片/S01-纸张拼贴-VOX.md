## 什么时候用

- 2 分钟内的知识科普、观点解释、冷知识。
- 抽象概念需要「变成可看的物件」：微波、通胀、算法、社会角色。
- 想要强烈的「手工感 / 编辑部感」，又不想做 3D。
- 不适合：人物传记（脸不够真）、长叙事（5 分钟以上会腻）、需要真实影像证据的题材。

## 镜头与动效

- 镜头**固定不动**，只让纸片逐件滑入、弹入、轻微旋转。
- 动作柔和克制，最后停在完整构图上；纸片有轻微抖动与投影变化。
- 禁止：整幅画面淡入、镜头切换或推拉、三维化、写实化、涂抹或改动原有中文标题文字与配色。
- 短片：5 拍 ×5s；长片：15 拍 ×8s，图生视频请求 6s，合成时 0.75× 缓放到 8s。
- 转场：拍与拍之间硬切即可；长片可用 0.3–0.5s 纸片擦除。

**动效锚点（直接复制）**：

```text

动作柔和克制，最后停在完整构图上；纸片有轻微抖动与投影变化。
禁止：整幅画面淡入、镜头切换或推拉、三维化、写实化、涂抹或改动原有中文标题文字与配色。
```

## 声音与字幕

- 旁白：豆包 TTS。纪录片男声 `zh_male_dayi_saturn_bigtts`；女声 `zh_female_xiaohe_uranus_bigtts`。
- 每拍旁白 ≤20 字（短片）/ ≤28 字（长片）；旁白总时长 ≤ 片长的 60%，留呼吸。
- 字幕：微软雅黑 46px、纯白、1px 黑边、底部居中、MarginV 30。
- BGM：轻快、无歌词、音量压在人声之下；片尾可留 1s 余味。

## 结构

**5 拍标准结构**：

| 拍 | 作用 | 例（微波炉） |
|---|---|---|
| 1 | 钩子：一个反常识问题 | 两分钟，一碗冷饭怎么就热了？ |
| 2 | 机制：把原理变成纸片动作 | 它不烤不煎，靠的是看不见的微波。 |
| 3 | 细节：放大关键一步 | 微波让水分子疯狂转身、摩擦生热。 |
| 4 | 对比：为什么有的行、有的不行 | 水多的汤饭热得快，干面包却热不透。 |
| 5 | 落点：一个能立刻用的动作 | 热饭前加一勺水，比多转两分钟更管用。 |

**长片 15 拍**：每 3 拍一个小段落（现象 → 机制 → 例子），最后 2 拍收束。

## 坑

- **原生帧率必须对齐**：Seedance 24fps 素材按 30fps 合成会产生约 20% 重复帧，观感发顿。先 `ffprobe` 再定时间线。
- **海报中文会错字**：3–5 张一组拼图，用视觉模型逐字核，别等 15 张全出完。
- **图生视频的 `--first-frame` 只认公网 http URL**，本机文件不行；海报生成返回的临时链接 24h 有效。
- **兜底链**：原海报重交 → 简化版海报（元素≤3，另存 `kf_<id>s.jpg`，不覆盖原图）→ 参考图模式。别为最后一拍无限等。
- **一次进程只保留一份内存副本**：要补图就把所有 id 塞进同一个 `gen_posters.py` 调用，后写的会覆盖先写的。
- 中文提示词走 gateway 的 Python CLI，别用 curl（MSYS 会毁 UTF-8）。
