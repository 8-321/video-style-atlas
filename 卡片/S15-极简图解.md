## 什么时候用

- 技术深挖、架构讲解、数学/CS 概念、文档视频、机制说明。

## 视觉系统

| 项 | 规格 |
|---|---|
| 画幅 | 16:9 / 1920×1080；30fps |
| 底色 | `#FAFAFA` 浅灰纸 |
| 主线条/文字 | `#1A1A2E`；次级 `#16213E`；弱化 `#6B7280` |
| 唯一强调 | `#E94560` 红 |
| 辅助深蓝 | `#0F3460`（仅结构，不做强调） |
| 材质 | 纸感细纹；线条手绘感可选；**线宽全片统一** |

| 禁止 | 彩色、活泼、3D、写实、拥挤 |

**硬规矩**：**红色是唯一的强调色**；图表一律单色 + 一个红点。

**风格锚点（直接复制）**：

```text
minimalist technical diagram, clean thin dark lines on light gray #FAFAFA background,
square nodes, monochrome with a single red #E94560 accent, blueprint-like precision,
consistent line weight, generous margins, grid-aligned, no color, no 3D, no photorealism
```

## 镜头与动效

- 场景停留：**3–15 秒**；文字卡 **4 秒**；数字卡 **3.5 秒**。
- 转场：`fade / dissolve`，**0.5 秒**。
- 入场：**路径描绘（SVG draw-in）** 或淡入上浮。
- 缓动：ease-out，**不弹跳、不过冲**。
- 讲关系时：节点依次出现 → 连线生长 → 关键节点变红。

## 声音与字幕

- 旁白：冷静、精确、像教授，术语可以出现但要马上解释。
- BGM：极简环境音/钢琴/合成器铺底；**音量 0.05**（近乎无）。
- 音效：笔画声、节点连接的轻「嗒」。
- 响度：−16 LUFS；ducking −2 dB。
- 字幕：等宽或人文无衬线，术语保留英文原词；单行 ≤18 字。

## 结构（120 秒标准）

| 段 | 时间 | 内容 | 作用 |
|---|---|---|---|
| 问题 | 0–10s | 一个具体问题/一张现状图 | 锚定 |
| 拆解 | 10–50s | 把系统拆成 3–5 个节点 | 建立结构 |
| 关系 | 50–90s | 连线、数据流、因果 | 讲机制 |
| 反例 | 90–105s | 一个会失败的边界情况 | 严谨 |
| 收口 | 105–120s | 一张总图 + 一句结论 | 记忆点 |

## 生产链

- 规范：`OpenMontage\styles\minimalist-diagram.yaml`
- 渲染：SVG + 路径动画（Remotion / HTML），比生成模型更准
- 可复用：`diagram_style`、`consistency_anchors`（4 条）、线宽规范
- 提示：图解不要用文生图，文字和连线必错；用代码画

## 验收数字

- [ ] 全片只有一个红色强调
- [ ] 线宽全片一致（记录 px 值）
- [ ] 节点对齐网格，没有「差 3px」
- [ ] 单镜 3–15 秒；转场 0.5 秒
- [ ] 每个节点都有文字标签，且无错字
- [ ] 动效无弹跳；连线是「生长」不是「闪现」
- [ ] BGM ≤0.05

## 坑

- **用生成模型画图解**：文字必错、连线必乱，一律代码画。
- **红色用两处**：强调就失效了，观众不知道看哪。
- **线宽不统一**：一眼看出是拼的。
- **信息塞满**：一屏超过 7 个节点就该拆成两屏。
