## 什么时候用

- 投资人更新、专家解说、产品叙事、高信任发布、B 端方案片。
- 45–180 秒，16:9；适合投屏和官网首屏。
- 信息要「显得可信」而不是「显得热闹」的场合。
- 不适合：抖音快节奏、情绪片、需要强视觉冲击的题材。

## 镜头与动效

- 场景停留：**2.75–12 秒**；文字卡 **3.75 秒**；数字卡 **3.25 秒**。
- 转场：`fade / dissolve / slide-left`，**0.45 秒**。
- 入场：淡入 + 上浮 **12px**；出场：柔和淡出 + 轻微位移。
- 缓动：克制的 ease-out，**不弹跳、不过冲**。
- 原则：**动效只用来建立层级，不用来装饰。**

## 声音与字幕

- 旁白：克制、专业、温暖、低 hype，像给董事会汇报。
- BGM：极简脉冲、干净合成器铺底；**音量 0.07**（几乎听不见）。
- 音效：小的触感「嗒」声、纸一样的轻擦声；极少。
- 响度：−16 LUFS（比娱乐内容更保守）；真峰值 ≤ −1.5 dBTP。
- 字幕：左对齐、单行 ≤16 字；不要居中大字幕。

## 验收数字

- [ ] 一帧一个焦点物，能指着说出来
- [ ] 三种版面在轮换，没有连用同一版式
- [ ] 强调色只有钴蓝（深青仅作辅助）
- [ ] 没有任何装饰性渐变
- [ ] 单镜 2.75–12 秒；转场 0.45 秒
- [ ] 动效无弹跳
- [ ] BGM ≤0.07，−16 LUFS
- [ ] 每帧「看起来是有意留白，不是没做完」

## 坑

- **一加渐变就变廉价**：高端感来自「克制」，不是来自光效。
- **版式不换会困**：连续三帧同一版式，观众立刻走神。
- **快切降理解**：这套的转化率靠「看得清」，不是「看得爽」。
- **中文用 Inter**：中文必须配 Noto Sans SC，否则字重不匹配。
