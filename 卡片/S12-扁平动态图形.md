# S12 扁平动态图形 · Flat Motion Graphics

> 一句话：深色底上只用色块、几何和粗字，每 2–3 秒换一个视觉元素，把「讲不清」讲成「一眼懂」。

## 什么时候用

- 社媒科普、产品发布、创业路演、数据讲解、SaaS 功能说明。

## 视觉系统

| 项 | 规格 |
|---|---|
| 画幅 | 16:9 / 1920×1080；竖屏 9:16 重排 |
| 底色 | `#0F172A` 深板岩 |
| 主色 | `#7C3AED` 紫、`#4F46E5` 靛 |
| 强调色 | `#EC4899` 品红、`#06B6D4` 青 |
| 文字色 | `#F8FAFC`，次级 `#64748B` |
| 材质 | **纯平色块 + 几何形状**；除背景外禁止渐变 |
| 字体 | 拉丁 Space Grotesk（标题 700 / 字距 −0.03em；数字卡 800）；中文 Noto Sans SC Bold |
| 构图 | 满幅、偏心、强框选；一屏一个主张 |
| 禁止 | 写实照片、3D 渲染、水彩、复古、白底、超过 4 色 |

**硬规矩**：一屏最多 4 色（深底算 1 色）；所有文字对比度 ≥ 4.5:1；720p 手机上必须能读。

**风格锚点（直接复制）**：

```text
flat vector illustration, bold colors, dark slate background #0F172A, geometric shapes,
purple #7C3AED as primary accent, magenta #EC4899 and cyan #06B6D4 as pops,
no gradients except background, no photorealism, no 3D, edge-to-edge bold framing,
high contrast, clean vector edges, generous negative space
```

## 镜头与动效

- 镜头停留：**1.5–8 秒**；文字卡 **2.5 秒**；数字卡 **2.0 秒**。
- 转场：`wipe-left / zoom-in / morph / cut`，时长 **0.3 秒**。
- 入场：`0.8 → 1.05 → 1.0` 回弹缩放；出场：缩小淡出。
- 缓动：`spring(1, 80, 10)`，允许轻微过冲。
- **每 2–3 秒必须出现一个新视觉元素**；每个转场配一个音效。
- 禁止：连续 5 秒静止；弹跳过度导致文字难读。

## 声音与字幕

- 旁白：能量高、口语、略快，Gen-Z 语气。
- BGM：lo-fi beat / 电子 / 有推进感的鼓点；**音量 0.12**（压得很低）。
- 音效：punchy pops、whoosh、关键帧 glitch。
- 响度：−14 LUFS；ducking 阈值 −4 dB。
- 字幕：粗体无衬线，单行 ≤12 字；关键词用强调色块反白，不用描边。

## 结构（60 秒标准）

| 段 | 时间 | 内容 | 作用 |

## 验收数字

- [ ] 一屏 ≤4 色
- [ ] 所有文字对比度 ≥4.5:1
- [ ] 每 2–3 秒有一个新视觉元素
- [ ] 单镜 1.5–8 秒，没有超长静止
- [ ] 转场 0.3 秒且都有音效
- [ ] BGM 音量 ≤0.12，不盖人声
- [ ] 720p 下最小字号仍可读

## 坑

- **加渐变就破功**：这套的力量来自「纯平」，一加光影就变成廉价 PPT。
- **颜色超 4 种**：立刻从设计变成信息图垃圾场。
- **节奏放慢**：这套风格靠密度撑，镜头停 6 秒以上就散。
- **中文直接套 Space Grotesk**：中文必须换 Noto Sans SC Bold，字重要对齐。
