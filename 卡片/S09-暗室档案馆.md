## 动效语气

| 内容 | 动效 | 理由 |
|---|---|---|
| 下定义 | 卡片从下方升起 + 细线扫过 | 有「盖章」的确定感 |
| 讲机制/因果 | 三个节点依次点亮 + 连线生长 | 让因果链可见 |
| 对比两种人格/观点 | 双栏从中间分开 | 结构本身就是论点 |
| 类型/八维数据 | 轴线上的点滑动到位 | 强调「倾向」而非「标签」 |
| 关键结论 | 背景压暗 + 单句浮出 | 留白制造重量 |
| 转场到电影片段 | 2 帧白闪 + 颗粒跳变 | 明确「进入例证」 |

**参数**：入场 0.28–0.45s ease-out，位移 ≤24px；一屏至少 1.6s；出场 0.2s 淡出或轻微下移。不做弹跳、不做旋转飞入。

## 声音与字幕

- 语速：中文 5.5–6.2 字/秒；哲学型放慢到 4.8–5.2 字/秒。
- 停顿：句间 0.18–0.25s；段落间 0.6–0.8s；重音前留 0.15s；结尾留白 1.2–1.6s。
- 响度：−14 LUFS，真峰值 ≤ −1.5 dBTP。
- BGM：解说下 ducking，不盖人声。
- 字幕：Noto Sans SC 600，44–52px；无描边，2px 深色投影（45%）；单行 ≤13 字，最多两行；关键词只标一个，用信号色 A，不加粗不放大。
- 中英双语：中文 48px 纸色；英文 30px 透明度 72%，位于主行下方 8px；术语用规范译名。

## 结构（4 条主线，选一条，不混用）

| 类型 | 时长 | 结构 |
|---|---|---|
| 心理学解析型 | 60–90s | 钩子 → 命名现象 → 机制解释 → 电影/案例 → 方法 → 落点 |
| 哲学追问型 | 45–75s | 反常识命题 → 拆解 → 反例/辩证 → 落点（允许留白） |
| MBTI/人格类型型 | 60–90s | 类型钩子 → 3 条行为特征 → 认知功能 → 纠偏 → 建议+互动 |
| 电影人物解析型 | 90–150s | 名场面 → 人物处境 → 理论命名 → 现实映射 → 落点 |

**钩子公式**：否定式「X 不是 Y，是 Z」/ 代价式「你越 A，就越容易 B」/ 命名式「这有个名字，叫 X」/ 反转式「你以为你在 X，其实你在逃避 Y」/ 类型式「如果你是 X 型，你一定经历过这个瞬间」。
