## 叙事公式

```
钩子（承诺数量+收益+对象 + 角色蒙太奇）
→ [身份 → 证明 → 职位] × 16
→ 停（不总结、不 CTA）
```

- 钩子 3 秒内必须说清「多少型 / 得到什么 / 给谁看」。
- 每块只给 1 个标签、1 个行为证明、3–4 个职业；信息量固定。
- 编号必须出现，制造倒计时和「等我的类型」。
- 四色分组让观众按组认领；同组同色系，靠轮廓/道具区分。
- 最后一个类型说完就停，目录式内容不需要总结。

## 生产链

1. 写 16 行表：`编号 / 类型 / 别名 / 组色 / 特征 / 行为证明 / 3–4 职业`。
2. 出 16 个角色设定图：同组同色系，固定发型/服装/道具；先审角色关。
3. 每型出 3 张 1280×720 PNG：hero / quote / jobs。
4. hero 用 ffmpeg `zoompan` 慢拉远 7s；quote/jobs 静止 4.17/3.33s；硬切 concat。
5. 旁白 5.9 字/秒；BGM 99 BPM；8 拍一切。
6. 抽 12fps 连续帧，和参考同位置并排；不看单帧。

## 坑

- **类型名 ASR 必错**：Whisper 会把 ISFJ/ISTJ/INTJ 听成 East/二/East；必须用屏上字校正。
- **jobs 背景不是统一浅色**：ISFJ 医院是浅灰，INTJ 战略室仍是紫色；共同点只有「静止 + 黄色职位」。
- **角色不能只换色**：同组四个类型如果只换衣服颜色，观众会认不出；必须换发型/道具/轮廓。
- **信息量必须固定**：某块多写两个职业，节奏就塌；每块 3–4 个，宁可删。
- **不要加转场**：参考片全靠硬切；叠化会让「目录感」变成「PPT 感」。
- **不要加 CTA**：最后一块说完就停；加「点赞关注」会破坏图鉴的干脆。
